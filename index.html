The Cipher Bureau

Three exhibits from the working file: a transposition cipher by hand, public-key encryption by machine, and a login desk that never learns your password.

Exhibit A · Field Cipher

Rail Fence Cipher

A transposition cipher: the message is written in a zig-zag across a chosen number of rails, then read off row by row. No substitution, no math — just geometry.

 
Exhibit B · Machine Cipher

RSA Public-Key Encryption

Generate a keypair, encrypt a message with the public key, and decrypt it with the private key. Only the private key holder can reverse the process.

Keys are generated in your browser and never leave it. Larger key sizes take longer to generate — 512/1024-bit is fine for demonstrating the mechanism.
Exhibit C · The Login Desk

Hashed Password Storage

Register a username and password below. The password itself is never stored — only its MD5 or SHA-256 digest is written to the record. Logging in re-hashes what you type and compares digests.
